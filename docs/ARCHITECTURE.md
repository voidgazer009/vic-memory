# Vic Memory 架构

```
            ┌─────────────────────────── 在线（每一轮） ───────────────────────────┐
 raw turn → │ ① 感觉门控 salience + novelty ─► ② 工作记忆 K 槽（溢出时：显著→晋升 / 否则遗忘）│
            └──────────────────────────────────────────────┬──────────────────────┘
                                                           ▼
   ┌──────────────────────────── ③ 长期记忆（SQLite 一个文件） ───────────────────────────┐
   │ episodic 情景   semantic 语义(key 槽位·双时序)   procedural 程序   prospective 前瞻 │
   │ 每条：salience 显著性 · confidence 置信度 · source 来源 · access traces 访问痕迹       │
   │ links：自动关联网络（卡片盒 / 海马体索引）                                            │
   └──────────────────────────────────────────────────────────────────────────────────┘
        ▲ ④ 回忆 recall(cue)                                   ▼ ⑤ 睡眠 sleep()（离线）
   词法 BM25(中英) 0.45 + 向量 0.25 + ACT-R 激活 0.15           衰减 → 归档（不删除）
   + 显著性 0.10 + 置信度 0.05 → 扩散激活 → 再巩固(强化)          近重复合并（痕迹汇总）
   as_of 时间旅行 · confident 元记忆（不知道就说不知道）          情景簇 → 语义抽象（可接任意 LLM）
```

## 关键公式
- **激活**（ACT-R）：`B = ln Σ t_j^(-d)`，`d = 0.5·(1 − 0.5·salience)`——越重要遗忘越慢；每次回忆加一条痕迹 → 间隔重复效应
- **保持度**：`retention = σ(B + 3·(salience − 0.5) + 1)`
- **元记忆覆盖度**：线索中被最佳记忆覆盖的 IDF 加权比例 ≥ 0.3 才算"真的知道"

## 为什么它比"大模型自带记忆"强
| 能力 | 长上下文 / 平台记忆 | Vic Memory |
|---|---|---|
| 超出窗口的久远信息 | 被截断 | 永久保存、按线索取回 |
| 事实变化 | 新旧并存，模型自己猜 | key 槽位自动失效旧值，历史可查 |
| "当时是什么情况" | 不支持 | `as_of` 时间旅行 |
| 不知道时 | 常常编造 | `confident=false` 明确拒答 |
| 成本 | 每轮重读全部历史 | 只注入 ~100–800 token |
| 换模型 / 换平台 | 记忆锁死在厂商 | 一个 SQLite + Markdown 导出，任意模型通用 |
| 可审计、可删除 | 黑盒 | 每条可见、可软删/硬删 |

> 注意：这是**架构能力**对比。数值评测见 `bench/RESULTS.md`（我们自建的合成基准，结果仅供参考）；LoCoMo / LongMemEval 公开复现在 v1.0 路线图中。
